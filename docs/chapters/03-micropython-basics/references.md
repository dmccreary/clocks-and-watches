# References: MicroPython Basics: Variables and Data Types

1. [MicroPython](https://en.wikipedia.org/wiki/MicroPython) - Wikipedia - Describes MicroPython as a compact Python 3 implementation for microcontrollers, with its history, supported boards, and interactive prompt. It frames what makes it different from desktop Python in this chapter.

2. [Python (programming language)](https://en.wikipedia.org/wiki/Python_(programming_language)) - Wikipedia - A thorough overview of Python's readable syntax, dynamic typing, built-in data types, and design philosophy. It explains why Python is a good first language and where this chapter's syntax rules come from.

3. [Variable (high-level programming language)](https://en.wikipedia.org/wiki/Variable_(computer_science)) - Wikipedia - Explains variables as named storage locations whose values can change, covering naming, scope, and typing. It supports this chapter's sections on variables, assignment operators, and data types.

4. Think Python: How to Think Like a Computer Scientist (2nd Edition) - Allen B. Downey - O'Reilly Media - Downey draws state diagrams with arrows from each variable name to its value, and ends chapters with debugging advice. These make variables and print debugging concrete for newcomers.

5. Python Crash Course (3rd Edition) - Eric Matthes - No Starch Press - Matthes, a former high school teacher, follows each short section with "Try It Yourself" exercises so students type code immediately. No single author originated the variables material; this book is praised for its clarity.

6. [The MicroPython Interactive Interpreter Mode (aka REPL)](https://docs.micropython.org/en/latest/reference/repl.html) - MicroPython Documentation - The official guide to the REPL prompt, including typing commands, paste mode, and auto-complete. It supports this chapter's hands-on work of testing values and expressions on the Pico.

7. [An Informal Introduction to Python](https://docs.python.org/3/tutorial/introduction.html) - Python Documentation - The official tutorial's friendly tour of numbers, strings, and lists using short examples at the prompt. It reinforces the chapter's integers, floats, strings, lists, and arithmetic operations.

8. [Thonny, Python IDE for beginners](https://thonny.org/) - Thonny - The home of the beginner-friendly editor used in this book, with download links and a summary of features such as its variable viewer and debugger. It supports the chapter's Thonny IDE setup section.

9. [Python String Formatting](https://www.w3schools.com/python/python_string_formatting.asp) - W3Schools - Short interactive examples of f-strings, placeholders, and number formatting. They help students build output like a zero-padded 12:34:56 clock display, matching the chapter's f-string formatting section.

10. [Getting Started with Thonny MicroPython (Python) IDE](https://randomnerdtutorials.com/getting-started-thonny-micropython-python-ide-esp32-esp8266/) - Random Nerd Tutorials - A step-by-step tour of the Thonny window, shell, and interpreter selection for MicroPython boards. It targets ESP boards, but the interface matches the Pico workflow in this chapter.
